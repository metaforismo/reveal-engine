# Certification boundary

This repository provides source code, deterministic fixtures, conformance checks, tests, and synthetic performance evidence. It is not a fairness certificate, RNG certificate, mathematical certification, regulatory approval, penetration-test attestation, production-capacity claim, or proof of a deployed game's RTP.

A passing compatibility report is shadow engineering evidence only. `ok` does not mean `activationReady`, unchanged RTP, production adoption, or certification. Expected legacy-proof/derivation differences, payable deltas, and host-managed continuation remain migration work even when correctly classified.

A deployment requires its own frozen configuration, independently reviewed RNG/seed custody, operator integration and wallet audit, jurisdictional analysis, payable simulation, reserve/risk model, production load evidence, incident controls, and any required laboratory/regulatory process. Changes to adapters, rounding, caps, continuation, storage, or callbacks can invalidate repository-level evidence.
