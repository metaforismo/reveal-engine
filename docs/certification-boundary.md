# Certification boundary

This repository provides source code, deterministic fixtures, conformance checks, tests, and synthetic performance evidence. It is not a fairness certificate, RNG certificate, mathematical certification, regulatory approval, penetration-test attestation, production-capacity claim, or proof of a deployed game's RTP.

A deployment requires its own frozen configuration, independently reviewed RNG/seed custody, operator integration and wallet audit, jurisdictional analysis, payable simulation, reserve/risk model, production load evidence, incident controls, and any required laboratory/regulatory process. Changes to a lifecycle module, a definition, rounding, caps, continuation, storage, or callbacks can invalidate repository-level evidence.
