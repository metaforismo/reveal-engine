1. The read-only title behavior is frozen in `compatibility-corpus-v1` at branch `v8-signal-identity`, revision `7c63ebae28756df3b0ae96b917db37791cfcc588`, with relevant source hashes and the preserved deleted PDF/untracked `.claude/` status recorded as provenance.

3. The frozen shadow comparison covers 64 truth/evidence seeds, 256 posterior checkpoints, 4,096 title-evidence economic paths, and four cap cases. It reports 18/64 equal truths, 0/64 equal schedules, 1,182 +1¢ sell deltas, 14 +1¢ winning-settlement deltas, exact posterior parity, and exact cap/continuation behavior.
4. Legacy truth/evidence and delimiter commitment remain explicitly different from engine `commit-v2`. Early payable rounding remains a visible economic migration decision. RIDE offer expiry, wallet/history, and cross-round chain state remain title-owned.
5. A title adoption PR must choose and version an economics policy, add a browser-safe `commit-v2` verifier, bridge title frame IDs to evidence revisions, retain/replay legacy liabilities, and review the cross-round ride ledger before activation.
6. Independently review operator integration, seed custody, payable simulation, reserve risk, production load, and certification scope before activation.

Private dependency blocker: the package is private/unpublished, `dist/` is not tracked, and Git installation has no `prepare` build. A reproducible title dependency therefore still needs a separately authorized mechanism such as an immutable private registry/release artifact or a compiled `npm pack` tarball pinned by engine Git SHA, tarball SHA-256, and lockfile integrity. This repository does not write that artifact into the BLACK SIGNAL checkout.

The adapter and corpus are compatibility references, not evidence that BLACK SIGNAL consumes the package, has migrated, retains unchanged payable RTP, or is certified.
